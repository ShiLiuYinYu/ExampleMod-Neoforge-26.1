# 目录结构组织

> NeoForge 26.1 模组项目标准目录结构

---

## 项目根目录

```
<项目名>/
├── build.gradle              # Gradle 构建脚本（模组依赖、运行配置、数据生成）
├── settings.gradle           # Gradle 设置（插件仓库、工具链）
├── gradle.properties         # 构建属性（MC 版本、模组 ID、版本号等）
├── gradle/                   # Gradle Wrapper
├── gradlew / gradlew.bat     # Gradle 启动脚本
├── .gitignore
├── .gitattributes
├── .github/                  # GitHub 工作流（CI 等）
├── document/                 # 项目文档（非代码）
└── LICENSE.txt
```

## 源代码目录：`src/`


## 关键目录说明

| 目录 | 说明 | 手动/自动 |
|------|------|----------|
| `src/main/java/` | Java 源代码 | 手动编写 |
| `src/main/resources/` | 静态资源（纹理、手动 JSON） | 手动维护 |
| `src/main/templates/` | Gradle 处理模板 | 手动维护 |
| `src/generated/resources/` | 数据生成器输出 | 自动生成（runData），**不可手动编辑** |

## 包名规范

包名 = `mod_group_id`，遵循 Java 反向域名规范：

```
com.<团队名>.<modid>
```

- 全部小写，不含大写字母
- `modid` 必须满足正则 `[a-z][a-z0-9_]{1,63}`
- 与 `gradle.properties` 中的 `mod_id` 保持一致
